# Upper Story Turing Tumble Simulator

Build, run, and explore marble-powered computers in your browser with the **Upper Story Turing Tumble Simulator**.

Use the simulator to experiment with your own designs, recreate setups from the puzzle book, or demonstrate how a machine works. Teachers can display the board on a classroom screen so students can follow marble paths, predict outcomes, and discuss solutions together while working with their physical games.

**[Open the simulator](https://marblepower13.github.io/upperstory-turing-tumble/)**

No installation or account is required to play.

## Getting Started

1. Select a component from the **Parts** panel.
2. Click a peg on the board to place it.
3. Choose **Select / Flip** to change the orientation of components that support it, or drag a placed component to move it.
4. With **Select / Flip** selected, click a marble-release mechanism at the top of the board to start the machine.
5. Watch how the marbles interact with the components and change the machine's state.

The simulator includes ramps, crossovers, interceptors, bits, gear bits, and gears. Hover over any button for an explanation of its function.

## Board Controls

| Control | What it does |
|---|---|
| **Select / Flip** | Interact with the machine, flip supported components, and drag components to move them. |
| **Remove part** | Remove placed components while keeping board pegs and fixed board pieces intact. |
| **Add marbles** | Click either top holding area to add a marble. Its color automatically matches that supply. |
| **Zoom in / Zoom out** | Enlarge or reduce your view of the board. |
| **Fit board to screen** | Center the board and adjust the zoom to show the entire board without changing its size or peg count. |
| **Faster / Slower** | Adjust the simulation speed. The slowest setting pauses the machine; Faster resumes it. |
| **Return marbles** | Return marbles to their supplies while keeping placed components and their current orientations. |
| **Reset all** | Clear placed components and restore the standard board with eight blue and eight red marbles. Confirmation is required. |

**Return marbles does not restore the starting states of bits or gear bits.** Check their orientations before rerunning a machine.

## Using the Simulator in Class

Build a machine on screen and invite students to predict its behavior before releasing a marble. Slow down the simulation to examine individual interactions, or pause to discuss how a bit changes state and how connected gear bits affect one another.

Students can compare the on-screen machine with their physical boards and explain how their designs produce the intended result.

Find teaching materials on the [Turing Tumble Educator Resources page](https://www.upperstory.com/en/turingtumble/edu/resources/).

## Additional Tools

Open **Advanced** for extra building tools, schematic view, optional board resizing, and controls to save or reopen a board file.

Select **Help** for instructions at any time.
